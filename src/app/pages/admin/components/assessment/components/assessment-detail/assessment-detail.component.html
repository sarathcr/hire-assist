@if (selectedGuideTab === "aptitude") {
Phase 1

Assign Batch

  • Select candidate(s) via checkboxes.

Phase 2

Schedule Test

  • Click the Schedule row button in candidate's row.
  • Select their exact start Date & Time to send email invitations.
Phase 3

Monitor Status

  • Candidates receive invites and start their test.
  • Monitor live progress state: Assigned ➔ In Progress ➔ Completed.
Phase 4

Evaluate Candidates

  • Review test score reports and completion metrics in the candidate table.
  • Use the Actions dropdown to mark candidates as Select Candidate, On Hold Candidate, or Reject Candidate.
  • Place candidates On Hold if they need borderline score review, additional evaluation, or deferred decision.
  • Use the Unlock action (available if a test terminated prematurely) to reset and allow technical retries.
